# 📚 Re-Search Book  
### Academic Resource Platform (2024–2025)

Re-Search Book is a digital academic resource platform designed to help students easily access organized study materials such as notes, e-books, and previous year questions.

The platform focuses on structured content presentation, efficient filtering, and responsive user experience.

---

## 📌 About The Project

This platform was developed to solve a common student problem — scattered academic resources.

Re-Search Book centralizes study materials into one organized web interface, allowing students to quickly search and access relevant content.

---

## 🛠 Tech Stack

- React.js
- JavaScript (ES6)
- CSS3
- REST API integration (content delivery)
- PDF resource handling

---

## ✨ Core Features

- 📂 Category-based filtering (Notes, E-books, PYQs)
- 🔎 Keyword-based search functionality
- 📄 Direct PDF resource access
- 📱 Fully responsive UI (Mobile + Desktop)
- ⚡ Fast content rendering
- 🎯 Clean and minimal academic interface

---

## 🧠 How It Works

1. Resources are structured by category
2. React state management handles filtering logic
3. Keyword search dynamically filters displayed resources
4. Users can directly open/download attached PDFs
